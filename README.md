# Macrohard Official Website Clone (Netlify Bundle)

**Lead Architect & Developer:** Tamojit Roy

## Overview
A pixel-faithful, fully responsive clone of the Microsoft storefront and cloud ecosystem website (`Macrohard`), engineered to scale seamlessly from 320px mobile screens up to 4K displays without UI breakage.

## Included Files
- `index.html` — Main responsive storefront & entry point
- `css/styles.css` — Fluent Design System stylesheet & responsive media rules
- `js/app.js` — Interactive hero carousel, storefront filter, side-by-side spec comparator, Copilot AI sandbox, M365 plan selector, and live shopping cart
- `assets/` — Custom SVG/PNG favicons (`favicon.svg`, `favicon.png`), `favicon.ico`, and optimized studio product photography
- `netlify.toml` & `_redirects` — Zero-config Netlify deployment and caching rules

## How to Deploy on Netlify
1. **Drag & Drop:** Unzip `macrohard_netlify_bundle.zip` and drag the folder directly into [app.netlify.com/drop](https://app.netlify.com/drop).
2. **Git Deploy:** Push this directory to GitHub/GitLab and connect the repository in Netlify (Publish directory: `.`).
